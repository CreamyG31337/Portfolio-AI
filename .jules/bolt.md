## 2025-07-03 - [Vectorized String Normalization in Pandas]
**Learning:** `pandas` `.apply()` on string variations acts as a Python for-loop, causing bottlenecks inside aggregation steps. The fallback `.fillna(df['original'])` behavior in a vectorized `.map()` might introduce minor whitespace bugs if the original series wasn't properly `.str.strip()` prior to evaluation, unlike `.apply()` which evaluates and returns per-row dynamically.
**Action:** Always pre-compute vector transformations (like `.astype(str).str.strip()`) into temporary Series before executing dictionary lookups via `.map()` to preserve identical functional coverage over unmapped items. Be careful not to pollute the repo with benchmarking scratchpad files.
